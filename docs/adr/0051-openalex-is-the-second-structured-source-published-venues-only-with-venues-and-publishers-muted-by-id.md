# 0051: OpenAlex is the second Structured source — published venues only, with venues and publishers muted by ID

**Status:** Accepted

Issue #778 asked for Scouts beyond arXiv and watched pages, naming Google Scholar. ADR 0016 had left a second Structured source as a later beat; research #132 (`docs/research/0132-literature-apis.md`, on its own branch) recommended Semantic Scholar or OpenAlex. The aim the maintainer gave is a central place to search **published** venues, since arXiv does not require peer review. This ADR records the calls from the triage and `grill-with-docs` pass. OpenAlex filter and field names were checked against the live API on 2026-10-21, keyless.

## Decisions

1. **Google Scholar is not a source** (`.out-of-scope/google-scholar.md`): it has no API and forbids automated queries; scraping fails as a quiet field, and a paid proxy sends queries to a service that is not the model provider (ADR 0048). **OpenAlex is the second Structured source.** Semantic Scholar stays a later, separate decision.
2. **A third Scout source kind, `openalex`,** beside `arxiv` and `watched`. A Scout keeps its kind (ADR 0016 decision 4 and the form already refuse a change), so no existing Scout migrates. The four run error kinds (`network`, `http`, `rate_limited`, `parse`) are reused so the `scout_runs` CHECK needs no rebuild; the fault sentences take a source name instead of the word "arXiv".
3. **Published venues only, fixed and not switchable.** Every OpenAlex Scout sends `primary_location.source.type:journal|conference` and `is_retracted:false`; a work whose primary location is a repository (arXiv among them) is not asked for, and preprints are what arXiv Scouts are for. The card says *journal* or *conference* and never *peer-reviewed*: no API can verify review, and a journal is not a reputable one. The Scout form says a preprint-only work will not appear, so that is not read as a gap.
4. **Filter: Tags or a Query, never both** (ADR 0046 decisions 1–6 hold). This **amends ADR 0046 decision 7**: Tag Filters are for the arXiv and OpenAlex sources. Tags compile through the existing OpenAlex compiler (ADR 0018 decision 5) into `title_and_abstract.search`; a Query is written in OpenAlex search syntax. A Scout with no Tag that compiles fails by name, as an arXiv one does.
5. **Keyless only.** An OpenAlex key would be a second credential leaving the device for an origin that is not the model provider, and would need its own ADR amending ADR 0048. The keyless budget ($0.10 a day, 1,000 credits) is **shared by every client on the same IP address**, so a spent budget is shown as *waiting, resets at midnight UTC* and never says the user spent it. A 429 or `x-ratelimit-remaining: 0` waits until the reset header, as `openalex.ts` already does.
6. **One OpenAlex client for the whole app, and the scatter yields.** The Attention scatter's sync (ADR 0045) and Scouts draw on the same budget. They share one client, so an exhausted budget is known to both, and the sync stops when `x-ratelimit-remaining` falls under a reserve of **300 credits**, saying it paused to leave room for Scouts and resuming after the reset. A search list call costs 10 credits and a filter-only count 1.
7. **Page 200, ceiling 400 works a run, lookback 60 days** — three named constants. A run that reaches the ceiling says so, as an arXiv run does (ADR 0016 decision 11). OpenAlex dates a journal work by publication date, which can precede the day OpenAlex indexed it (`from_created_date` is paid-only), so a window opened at the last run's end would miss late-indexed work; every run re-asks the previous 60 days and the existing source-key dedup absorbs the repeats. *Also search back to* works as for arXiv, bounded by the same ceiling.
8. **The vault-wide list is the Mute rules of ADR 0044, extended;** there is no second mechanism. A `publisher` kind is added. A `venue` rule stores the venue's OpenAlex source ID beside its name and **matches by ID** when the Proposal has one, falling back to the existing name match otherwise, so current rules and arXiv Proposals behave as before. A publisher rule matches the work's publisher lineage, so a rule on a parent also catches its imprints. Muted works are still fetched and spend the ceiling; the existing *N muted* is the count, and deleting a rule returns them. Server-side exclusion to save credits is left as a later optimisation if the ceiling proves too tight.
9. **A per-Scout venue allowlist** is `filter.venues` on the Scout's file: a list of OpenAlex source IDs with names, sent as `primary_location.source.id:S…|S…`. It narrows what the Scout asks, so it is not a mute. A Scout with an allowlist that returns nothing says the allowlist did it. Venues and publishers are added to either list through a name search over OpenAlex's source and publisher records, run on an explicit press, never as-you-type (10 credits a search); results show publisher, ISSN and works count to tell near-duplicates apart.
10. **Identity is unchanged:** an arXiv id (read from a location whose source is the arXiv repository), else a DOI, else the normalised link (ADR 0017). An OpenAlex Scout and an arXiv Scout finding one work make one Proposal with two Appearances.
11. **A later sighting fills what is missing and never overwrites.** The journal link becomes the main link once any Appearance has one; the arXiv link stays as *also on arXiv*. Venue, publisher and ID are filled from whichever Appearance supplies them, which can move an arXiv-first card into the muted view, by design (a rule is applied when read). An accepted stub is not rewritten.
12. **Card fields are the source's, never composed:** the abstract is reconstructed from OpenAlex's inverted index and shown as published; none shows as missing. *Try* is kept, with the total and first five titles, and shows the credits left from the response header.

## Considered options

- **Google Scholar through scraping or a paid proxy.** Rejected, decision 1.
- **Semantic Scholar alongside OpenAlex now.** Rejected: its coverage overlaps OpenAlex heavily and each source costs a client, a compiler, health sentences and a form option; its unique value (citations) has no consumer yet.
- **A separate blocklist, excluded server-side.** Rejected, decision 8: two vault-wide hide mechanisms with different behaviour, and excluded works are neither countable per entry nor recoverable.
- **An optional free OpenAlex key.** Rejected for now, decision 5.
- **A switch to include preprints on an OpenAlex Scout.** Rejected, decision 3.
- **An exact window like arXiv's.** Rejected, decision 7: it silently misses late-indexed work.
- **First sighting wins; newest overwrites.** Rejected, decision 11.
